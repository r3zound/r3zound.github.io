为 ZTE 中兴系 CPE（MU3351 / V50）内置 Android 虚拟机里跑的 OpenWrt 构建固件包。GitHub Actions 自动编译，输出 1GB ext4 rootfs 发到 Releases。

要点

  • 目标运行环境：ARMv8（aarch64）、OpenWrt 25.12.5、内核 6.12.94、APK 包管理。
  • 1GB sparse ext4 镜像，无分区表；首次启动由 resize2fs /dev/vda 自动扩容。
  • 配套做了个在线定制页（下方直接可用）：勾选插件 → 一键复制 inputs 到剪贴板 → 跳到 Actions 点 Run workflow，全程不需要 GitHub token。
