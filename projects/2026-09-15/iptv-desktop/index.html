IPTV 播放列表工具（Windows 绿色版）

  • 2026-09-15
  • 实用工具
  • GitHub 源码
  • 返回索引

轻量级单用途命令行工具。抓公共 m3u 源，做 4 层过滤后交给 PotPlayer 播放。绿色版，拷到哪都能双击运行。

要点

  • 四层过滤：URL 黑名单正则 → 剔除非中文频道 → 剔除上游标注的地域屏蔽频道 → 全量 HEAD 探活（1.5s 超时 / 16 路并发 GET-Range）。
  • 按 URL 与归一化频道名双重去重，每个频道最多保留 3 个可用 URL。
  • 六层排序：CCTV → 31 个省级卫视 → 热门地方台 → 港澳台 → 其他中文 → 外语，第一版数顺序而非字母序。
  • 全流程约 1-2 分钟（探活约 1 万频道），结束后自动拉起 PotPlayer 并关闭控制台。
