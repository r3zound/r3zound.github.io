  • 2023-11-25

GitHub Actions 云编译 OpenWrt 固件的模板仓库。把 .config 推进仓库，在 Actions 页面点一下就能出固件，不用自备编译机。

要点

  • 以 P3TERX 的 Actions-OpenWrt 模板为基础搭建，README 仍是模板原文，在此基础上按自己的机型调整构建流程。
  • 适合手里没有编译环境、只想白嫖 GitHub Actions 编译资源的人。

说明：说明：这个仓库本质是构建模板，代码主体来自 P3TERX 的开源模板，我这边做的是机型适配与流程调整，故放在自研区但标注清楚出处。
