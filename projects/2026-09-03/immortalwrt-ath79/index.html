为 EdgeLink EL-953（QCA9531 工业 4G 路由）做的 ImmortalWrt 21.02 自包含编译工程，把源码树全部收进仓库。

要点

  • README 里沉淀了完整的硬件参考表：16MB SPI NOR / 128MB DDR2、Quectel EC200T（CDC-ECM，2c7c:6026）、4 颗可控 LED 的 GPIO 映射、Breed 刷机分区表。
  • 固件选型带上 modeminfo / atinout / cdc_ether / USB-serial 这一整套 4G 调试链路。
  • 明确写明板子上没有 USB / TF / miniPCIe 扩展口，避免后来人踩坑。

说明：已归档：本仓库已被 OpenWRT-25.12-QCA953X 继承，后续工作全部在那边进行，此处仅作历史参考。
